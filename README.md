# 物业办公协作助手 v0.8.24

面向物业人员的通用办公技能，协助处理通知和函件、商户沟通、欠费台账、保洁巡检记录、合同资料与工作汇报。需要模板或样例时按任务说明并向使用者索取。

## 安装与使用

将本目录整个放入目标 Agent 支持的技能目录，按该平台的方式加载 SKILL.md；不同平台的导入、文件访问和 Python 能力可能不同。可直接说“帮我根据这些记录整理保洁整改清单”或“根据这份模板拟一份催缴函，缺失信息标待确认”。

如平台支持本地技能目录且有 Python 3.9 或更新版本（本机实测 3.12，其他版本需检查），可从本技能目录运行 python scripts/install_skill.py --target "目标技能父目录/property-work-assistant"。目标必须是绝对路径且父目录已存在；需先确认对应平台支持此目录。已有同名技能时默认不覆盖；更新时须额外指定 --backup-to "同一磁盘、技能目录之外的新备份路径"，旧目录先移动到备份路径。安装工具不联网、不安装依赖，也不能证明平台已识别或能执行技能。使用平台自身的导入方式也可以。

技能包含基础 Word/Excel 读写、通知图片生成、偏好文件、Word 模板定点填充、受限 Excel 数值填充，以及基于明确规则的欠费和保洁记录跟进工具。v0.8.20 包含 Windows 系统 WinRT 图片及扫描 PDF OCR 后备脚本；仅支持 Windows PowerShell 5.1、系统中文 OCR 语言包及 PDF WinRT 渲染组件，输出只作待核对转录稿。按系统现行执行策略运行本机脚本，不要求更改或绕过策略。运行 python scripts/check_environment.py 可检查本机 Python 依赖和临时目录。文件与偏好脚本依赖及实际限制见 references/office-capabilities.md。Word 模板填写应逐份核对结构和页面，不能保证全部模板版式不变。

现有能力不足时可尝试搜索适配技能，搜索失败则继续使用可用的平台能力。公开搜索服务会收到查询关键词；只使用不含内部信息的通用关键词。是否能自动调用其他技能取决于平台与权限。

## 第三方源码

本轻量试用包不包含第三方源码。八个上游项目的固定提交、下载地址、哈希和许可证见 references/upstream-manifest.json；完整离线归档仍保留在既有 v0.7 完整版本中。确有需要且网络可用时，可运行 python scripts/restore_upstreams.py --name 项目名 下载、校验并解压单个项目；技能目录不可写时可追加 --dest 指定允许写入的目录。上游项目未全部执行或业务验收。

## 当前验证范围

已用虚构样例在本机验证基本文件读取和生成、部分 Word 定点填充及单个复杂模板的结构和 WPS 渲染、公开技能目录搜索，以及一张中文图片的 WinRT OCR 调用。该 OCR 样例含编号连字符与标点误识，不能当作准确率通过。不同平台、新会话自动发现与调用、真实物业资料和使用者业务验收仍需测试。平台是否支持读取图片、OCR、生成图片及跨会话保存偏好须按实际环境确认。

## 离线自测

安装所需依赖后，可运行 python tests/test_core.py。测试只使用临时生成的虚构资料，不联网或处理用户文件；若依赖缺失导致跳过，命令会报告测试不完整并返回非零状态。通过仅表示所测脚本功能正常，不能代替实际平台自动调用或业务验收。
