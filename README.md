# 物业办公协作助手

面向物业人员的通用办公技能，协助处理通知和函件、商户沟通、欠费台账、保洁巡检记录、合同资料与工作汇报。需要模板或样例时按任务说明并向使用者索取。

## 安装与使用

将本目录整个放入目标 Agent 支持的技能目录，按该平台的方式加载 SKILL.md；不同平台的导入、文件访问和 Python 能力可能不同。可直接说“帮我根据这些记录整理保洁整改清单”或“根据这份模板拟一份催缴函，缺失信息标待确认”。

技能包含基础 Word/Excel 读写、通知图片生成、偏好文件和 Word 模板定点填充工具。文件与偏好脚本依赖及实际限制见 references/office-capabilities.md。Word 模板填写应逐份核对结构和页面，不能保证全部模板版式不变。

现有能力不足时可尝试搜索适配技能，搜索失败则继续使用可用的平台能力。公开搜索服务会收到查询关键词；只使用不含内部信息的通用关键词。是否能自动调用其他技能取决于平台与权限。

## 第三方源码

八个上游项目的完整固定版本源码以 ZIP 或 ZIP 分片保存在 assets/upstream-archives/，地址、版本、哈希及许可证见 references/upstream-manifest.json。按需运行 python scripts/restore_upstreams.py --name 项目名；脚本验证哈希并解压至 assets/upstream/，不会覆盖现有文件。原作者许可证在相应归档和解压目录内。上游项目未全部执行或业务验收，不能视为已经接入或经过安全审计。

## 当前验证范围

已用虚构样例在本机验证基本文件读取和生成、部分 Word 定点填充及单个复杂模板的结构和 WPS 渲染、公开技能目录搜索。不同平台、新会话自动发现与调用、真实物业资料和使用者业务验收仍需测试。平台是否支持读取图片、OCR、生成图片及跨会话保存偏好须按实际环境确认。
