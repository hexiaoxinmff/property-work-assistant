# 反馈记录与迭代

## 记录模板

- 日期、场景和任务（不写商户、个人或合同敏感信息）：
- 原结果的具体问题、影响和可复现的脱敏例子：
- 用户纠正及来源：
- 适用范围：仅本次 / 候选通用规则 / 已确认的长期偏好：
- 建议规则、例外与依据；必要时注明待业务确认：
- 下次验证方法和结果：未验证 / 已验证 / 不适用，记录实际边界：
- 版本、保存位置与后续读取方式：

每次只将有依据的改动纳入适用范围，出现冲突优先现行任务要求和经确认的最新依据。执行规则前检查适用条件；禁止把一次性样例中的姓名、数字、条款和当地习惯直接固化到通用技能。记录与规则应允许检查、纠正和回退。

迭代循环：接收反馈 → 修改本次结果 → 识别适用范围 → 记录候选规则 → 使用脱敏正例和反例验证 → 用户确认需长期保留的偏好及业务规则 → 在具备权限和实际保存能力时更新相应记录或技能 → 报告变更及未验证事项。若无权限或记忆能力，交付可复制记录并告知下次带回；不会自动跨会话学习。
