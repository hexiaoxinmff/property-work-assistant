# Excel 现有模板的受限数值填写

优先使用平台原生表格工具。若使用者明确指定已有 XLSX 的某个数值单元格、原值和新值，且条件满足，可使用 fill_xlsx_numbers.py 另存新文件：该工具只改现有数值节点，不支持新增单元格、文字替换、.xlsm，也不支持含公式、数字签名或保护的工作簿，以及目标工作表中含合并单元格、数据验证或保护的情况。超出范围要换可用工具或明确说明，不能擅自解除保护或重建模板。

输入 JSON 计划为对象列表，例如：[{"cell":"B2","expected":"1234.5","value":"900.25"}]。地址使用大写 A1，原值和新值是数字字符串。命令：python scripts/fill_xlsx_numbers.py TEMPLATE.xlsx --sheet 台账 --plan PLAN.json --out NEW.xlsx。

工具先检查原值、目标及文件类型，再输出新文件，验证其他包成员字节一致、工作表 XML 只变化计划内数值；不覆盖原文件或已存在文件。处理结果仍须核对业务数字，并在目标 Excel/WPS 中检查显示、打印和视觉效果；条件格式和图表可能随数值变化，结构一致不意味着外观像素完全不变。本机有限虚构样例验证有数字格式、字体、边框、行列尺寸、条件格式和第二工作表；不代表其他模板已验证。

页面检查须同时核对导出内容、缩放和可读性；若渲染出现异常，重新验证并报告，不能仅以文件结构一致判定页面通过。\n
